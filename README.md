# TabAdmin for Sublime Text

Plugin para administrar pestañas sin guardar en Sublime Text.

## Funciones

- Listar pestañas sin guardar.
- Respaldar todas las pestañas sin guardar.
- Cerrar pestañas vacías sin guardar.
- Cerrar todas las pestañas sin guardar.
- Alertas automáticas en:
  - 10 pestañas
  - 25 pestañas
  - 50 pestañas
  - 100 pestañas
- Crear respaldo directamente desde las alertas.

## Compatibilidad

Desarrollado inicialmente para Sublime Text 3.
